How it works

  1. Install the GitHub App on a repo. Within an hour you get an issue with the dependency map: every API, SDK and MCP server the code calls, watched or not.
  2. Watch. Specs, MCP servers, package registries and changelogs are polled daily. A breaking change becomes a GitHub issue naming the files and lines in your repo that it hits.
  3. Fix. With fix.mode: pr Kintsua opens a branch, patches the call sites in a sandbox, runs your tests and opens a PR only when they pass.
